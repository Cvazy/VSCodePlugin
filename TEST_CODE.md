## Тестовый пример

Этот код используется для проверки корректности генерации ассемблерного листинга и работы **Mapping** (синхронной подсветки).

### Исходный код (`test.c`)

```c
#include <stdio.h>

// Простая функция для проверки вызова (bl _sum) и арифметики (add)
int sum(int a, int b) {
    return a + b;
}

int main() {
    // Тест передачи аргументов и получения результата
    int result = sum(5, 10);
    
    // Тест работы со строковыми литералами и внешними функциями
    printf("Result: %d\n", result);
    
    return 0;
}
